# Contribution Guidelines | إرشادات المساهمة

Thank you for helping keep Awesome Salla useful. This list is maintained by [Grovlix](https://grovlix.com).

## Criteria for inclusion

An entry must meet all of these:

- **Public.** Anyone can open the link without an account, invite or payment wall. No private repositories.
- **Working.** The link returns a normal page, the project is not archived, and it has a real README. Community repositories should have a commit within the last two years, or be clearly useful.
- **Relevant.** It is directly about developing for Salla: its APIs, apps, themes, tooling, integrations or learning material.
- **No promotion.** No affiliate links, tracking links, personal data or pure marketing pages.

## How to add a link

1. One link per pull request.
2. Add it to the section where it fits best, in alphabetical order.
3. Use this format. Keep the description short, in English, and end it with a period:

   `- [Name](url) - description.`

4. Use the official name of the project. Do not include the platform name twice.
5. Check spelling and make sure the link has not been listed already.
6. Describe the entry honestly. If you are the author, say so in the pull request.

## Removing links

Open an issue or pull request if a link is dead, archived, or no longer relevant. Entries that stop working may be removed without notice.
